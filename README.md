# laboratorios-ios
Laboratorios sobre IOS en Xco de la aplicación cliente de GitHub. Se enfoca en SwiftUI, arquitectura recomendada (MVVM), y en el uso de Alamofire para consumir la API REST de GitHub. Los laboratorios 10, 11 y 12 están orientados a UI (listas, formularios, inputs y botones) y a integrar llamadas HTTP (GET y POST).
